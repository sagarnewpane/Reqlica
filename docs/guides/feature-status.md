# Feature status

Implemented workflows:

- Projects: create, list, start/stop, unregister, delete, and transfer.
- AI: saved conversations, specification input, draft edits, checks, and repairs.
- Publication: source/routes, revision checks, behavior tests, approval, activation.
- Contracts: generated OpenAPI, Swagger, and draft previews.
- Data: JSON/SQLite/related-record previews, datasets, confirmed insertion, baselines.
- Runtime: traffic rules, authentication simulation, CORS, logs, and request chains.
- Maintenance: environment variables, reviewed packages, schema plans, and migrations.
- Dashboard: static assets served by Python; no runtime Node.js server.

Implementation does not guarantee every provider or configuration works.
See [limitations](../limitations.md) and [future work](../roadmap.md).
