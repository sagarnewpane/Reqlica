      Open local dashboard ↗
      The launcher serves this file and forwards /gateway and /console requests to the local APIs, avoiding browser CORS. It reads the root .env, binds only to 127.0.0.1, and stops with Ctrl+C. Set REQLICA_UI_PORT to change 8080. This is a development server, not a production deployment.
